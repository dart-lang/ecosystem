## Visión general

Este repositorio alberga herramientas y paquetes generales del ecosistema Dart.

## Paquetes

| Paquete | Descripción | Versión |
| --- | --- | --- |
| [blast_repo](pkgs/blast_repo/) | Una herramienta para validar y corregir de forma masiva repositorios de GitHub. |  |
| [canary](pkgs/canary/) | Paquete de pruebas para verificar las actualizaciones en el ecosistema. |  |
| [corpus](pkgs/corpus/) | Herramienta para calcular el uso de la API por un paquete. |  |
| [dart_flutter_team_lints](pkgs/dart_flutter_team_lints/) | Un conjunto de reglas de análisis utilizado por los equipos de Dart y Flutter. | [![paquete en Pub](https://img.shields.io/pub/v/dart_flutter_team_lints.svg)](https://pub.dev/packages/dart_flutter_team_lints) |
| [firehose](pkgs/firehose/) | Herramienta para automatizar la publicación de paquetes en Pub desde GitHub Actions. | [![paquete en Pub](https://img.shields.io/pub/v/firehose.svg)](https://pub.dev/packages/firehose) |
| [repo_manage](pkgs/repo_manage/) | Herramientas diversas para consultar problemas, repositorios y pull requests. |  |
| [sdk_triage_bot](pkgs/sdk_triage_bot/) | Herramienta de automatización para la clasificación de problemas en dart-lang/sdk. |  |
| [trebuchet](pkgs/trebuchet/) | Herramienta para trasladar paquetes existentes a monorepos. |  |

## Repositorios mono de Dart

A continuación, se presenta un resumen de los repositorios principales del equipo de Dart:

| Repositorio principal | Descripción |
| --- | --- |
| [sdk](https://github.com/dart-lang/sdk) | El SDK de Dart, que incluye la máquina virtual, los compiladores para JS y Wasm, herramientas de análisis, bibliotecas principales y más. |

| SLO mono-repos | Descripción |
| --- | --- |
| [core](https://github.com/dart-lang/core) | Este repositorio alberga los paquetes esenciales de Dart. |
| [tools](https://github.com/dart-lang/tools) | Este repositorio contiene los paquetes relacionados con herramientas para Dart. |
| [labs](https://github.com/dart-lang/labs) | Este repositorio alberga los paquetes “labs” de Dart. |

| Repositorios temáticos | Descripción |
| --- | --- |
| [build](https://github.com/dart-lang/build) | Un sistema de compilación para Dart escrito en Dart |
| [ecosystem](https://github.com/dart-lang/ecosystem) | Este repositorio alberga herramientas y paquetes generales del ecosistema de Dart. |
| [http](https://github.com/dart-lang/http) | Una API compuesta para realizar solicitudes HTTP en Dart. |
| [i18n](https://github.com/dart-lang/i18n) | Un repositorio único para paquetes de i18n y l10n en Dart. |
| [leak_tracker](https://github.com/dart-lang/leak_tracker) | Un marco para rastrear fugas de memoria en aplicaciones Dart y Flutter. |
| [macros](https://github.com/dart-lang/macros) | Un repositorio de Dart para el desarrollo de macros. |
| [native](https://github.com/dart-lang/native) | Paquetes de Dart relacionados con FFI y el empaquetado de recursos nativos. |
| [shelf](https://github.com/dart-lang/shelf) | Middleware de servidor web para Dart |
| [test](https://github.com/dart-lang/test) | Una biblioteca para escribir pruebas unitarias en Dart. |
| [webdev](https://github.com/dart-lang/webdev) | Una CLI para el desarrollo web en Dart. |
